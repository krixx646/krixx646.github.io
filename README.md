# Agba Valentine Cheluchi — Portfolio

Standalone personal portfolio for GitHub Pages.

## Local preview

Open `index.html` in a browser, or:

```bash
python -m http.server 5500
```

Then visit http://127.0.0.1:5500

## Deploy to GitHub Pages

1. Create a public GitHub repo named **`krixx646.github.io`** (must match your GitHub username for user pages).
2. Push this folder:

```bash
git add .
git commit -m "Initial standalone portfolio"
git remote add origin https://github.com/krixx646/krixx646.github.io.git
git push -u origin main
```

3. In the repo: **Settings → Pages → Deploy from branch `main` / root**.
4. Site URL: **https://krixx646.github.io**
